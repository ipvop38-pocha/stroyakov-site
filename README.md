# Строяков-маркет

Восстановленная версия сайта из задачи «Восстановление чата», 4 сентября 2026 года.

## Локальная работа

Node.js 22.

```sh
npm ci --no-audit --no-fund
npm run dev
```

## Сборка и Layero

```sh
npm run build
```

Next.js настроен на статический экспорт. Готовый сайт находится в `out/`.
Параметры для Layero сохранены в `layero.json`: Next.js, Node.js 22,
установка `npm ci`, сборка `npm run build`, каталог результата `out`.
Репозиторий: `ipvop38-pocha/stroyakov-site`, ветка `main`, корень приложения `/`.

В настройках Layero отключить «Auto-promote default branch».
Сначала проверять preview, затем отдельно публиковать выбранную версию.
См. https://docs.layero.ru/deploys/github/ и https://docs.layero.ru/deploys/layero-json/.

`next start` не обслуживает статический экспорт: для опубликованной версии
используется статический хостинг Layero.

## Текущие ограничения

Каталог содержит 427 товаров: 329 из основной выборки Краснодара и 98 позиций
металла со склада «Основной склад Лабинск Родина». Для лабинских товаров
показывается склад; цена и единица продажи сохраняются из складского снимка.
«Заготовка из стали» исключена. Сетки и ленты находятся в отдельном разделе.

Названия оформляются по общим шаблонам группы и проверенной таблице
`catalog/title-overrides.json`. Химическая основа и способ нанесения фильтров
берутся из `catalog/product-facts.json` со ссылками на производителей.
Размеры и фасовка берутся из собственных складских данных. Название папки
склада не является доказательством бренда; у безымянных товаров бренд пустой.
Saturn использован только как образец оформления безымянных труб и саморезов.

Реестр источников покрывает 138 товаров; он не означает, что все характеристики
всех 427 товаров проверены. Неоднозначные старые серии и несовпадающие фасовки
требуют сверки упаковки. Неподтверждённые состав и способ нанесения не
добавляются в фильтры. Подробные описания, характеристики и большинство фото
остаются следующим этапом наполнения.

У всех 24 штукатурок подтверждены основа и нанесение: 12 гипсовых, 9 цементных,
2 цементно-известковых и 1 цементно-гипсовая. Ручное нанесение допускает 21 товар,
машинное — 12; 9 товаров входят в оба фильтра. Экспорт останавливается, если
штукатурка не имеет этих свойств или ссылки на подтверждающий источник.

Экспорт: `npm run catalog:export` после обновления обоих приватных снимков.
Проверки: `npm run catalog:check`, `npm run catalog:facets:check`,
`node --experimental-strip-types scripts/test-product-search.mjs`, `npm run build`.
Приватные снимки и отчёт `private/catalog-research/catalog-review.json`
не входят в репозиторий и статическую публикацию.

Это витрина с клиентской корзиной и избранным. Данные товаров и наличие
являются снимком, а не постоянной синхронизацией с МоимСкладом.
Серверную обработку заказов, отправку заявок и полноценную авторизацию
необходимо подключить отдельно перед приёмом реальных заказов.

В публичном коде не хранятся токены и внутренняя статистика отгрузок.
Секреты интеграций должны храниться только в защищённом серверном окружении.
