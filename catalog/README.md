# Подготовка каталога

`editorial.json` хранит названия для покупателей, описания, проверенные характеристики, источники, фото и параметры калькуляторов. Цены и остатки в этом файле не редактируются.

`app/catalog/products.generated.json` — публичный снимок для статического сайта. Он не содержит токен, себестоимость, документы продаж и объёмы продаж. Сборка на хостинге использует этот файл и не обращается к МоемуСкладу.

## Обновление

1. `npm run catalog:refresh -- "ПУТЬ_К_ЛОКАЛЬНОМУ_ФАЙЛУ_ТОКЕНА"` — прочитать текущие цены, единицы и свободный остаток выбранных товаров. Только GET-запросы. Выборка и настройки должны находиться в локальном `private/moysklad/`.
2. `npm run catalog:export` — обновить публичные данные готовых карточек и закрытую очередь подготовки остальных товаров.
3. `npm run catalog:check`, затем `npm run build`.
4. Опубликовать проверенную сборку через настроенный репозиторий и Layero. Один локальный экспорт не обновляет сайт в интернете.

Свободный остаток — физический остаток минус резерв, минимум ноль. Ожидаемые поставки не включаются. Время снимка отображается в карточке. Постоянной фоновой синхронизации пока нет.

Используется только «Розница ЛАБ.» в RUB. Нет цены — значение `null` и обращение к менеджеру; другие типы цен не подставляются. Розничные цены относятся к единице продажи из МоегоСклада. Изменение единицы требует проверки, чтобы не продать упаковку по цене килограмма.

## Готовность карточек

В экспорт входят только записи со `status: published`, прошедшие отбор по продажам, с описанием, характеристиками и существующим фото. Для новых карточек сохраняйте источники фактов и оригинал изображения производителя в закрытой папке подготовки. Не переносите характеристики между похожими сериями и размерами.

Фото Русгипс №6 утверждено пользователем и находится в `public/assets/products/00876-rusgips-6-v1.png`. У остальных четырёх ранее опубликованных товаров сохраняются прежние изображения (`photoStyle: legacy`) до подготовки новых.

Галерея показывает только существующее изображение. Варианты объединяются по явному `variantGroup`, а не по целой категории. Калькулятор появляется только при заданных подтверждённых параметрах: площадь листа либо масса мешка и расход смеси.
