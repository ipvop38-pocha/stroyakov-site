# Подготовка каталога

`editorial.json` хранит названия для покупателей, описания, проверенные характеристики, источники, фото и параметры калькуляторов. Цены и остатки в этом файле не редактируются.

`app/catalog/products.generated.json` — публичный снимок для статического сайта. Он не содержит токен, себестоимость, документы продаж и объёмы продаж. Сборка на хостинге использует этот файл и не обращается к МоемуСкладу.

## Обновление

1. `npm run catalog:refresh -- "ПУТЬ_К_ЛОКАЛЬНОМУ_ФАЙЛУ_ТОКЕНА"` — прочитать текущие цены, единицы и свободный остаток выбранных товаров. Только GET-запросы. Выборка и настройки должны находиться в локальном `private/moysklad/`.
2. `npm run catalog:export` — обновить публичные данные готовых карточек и закрытую очередь подготовки остальных товаров.
3. `npm run catalog:check`, затем `npm run build`.
4. Опубликовать проверенную сборку через настроенный репозиторий и Layero. Один локальный экспорт не обновляет сайт в интернете.

Свободный остаток — физический остаток минус резерв, минимум ноль. Ожидаемые поставки не включаются. Время снимка отображается в карточке. Постоянной фоновой синхронизации пока нет.

Используется только «Розница ЛАБ.» в RUB. Нет цены — значение `null` и обращение к менеджеру; другие типы цен не подставляются. Розничные цены относятся к единице продажи из МоегоСклада. Изменение единицы требует проверки, чтобы не продать упаковку по цене килограмма.

## Готовность карточек

В экспорт входят только записи со `status: published`, прошедшие отбор по продажам, с описанием, характеристиками и существующим фото. Для новых карточек сохраняйте источники фактов и оригинал изображения производителя в закрытой папке подготовки. Не переносите характеристики между похожими сериями и размерами.

Фото Русгипс №6 утверждено пользователем и находится в `public/assets/products/00876-rusgips-6-v1.png`. У остальных четырёх ранее опубликованных товаров сохраняются прежние изображения (`photoStyle: legacy`) до подготовки новых.

Галерея показывает только существующее изображение. Варианты объединяются по явному `variantGroup`, а не по целой категории. Калькулятор появляется только при заданных подтверждённых параметрах: площадь листа либо масса мешка и расход смеси.

## Изменения каталога — 07.09.2026

Классификация теперь находится в `scripts/catalog-taxonomy.mjs`: назначение из названия товара имеет приоритет над складской папкой. При неизвестном типе экспорт останавливается для проверки. Мётлы, веники и черенки исключаются по правилу пользователя; услуга доставки исключается отдельно. Идентификаторы и ранее опубликованные адреса сохраняются.

`catalog/merchandising.json` содержит только порядок ID для сортировки и четыре ID блока популярных. Порядок получен из `profit` отчёта МоегоСклада за 01.03–31.08.2026, склады Ростовское шоссе и ТРАНЗИТ; возвраты учитываются самим отчётом. На главную отбираются товары с положительной прибылью, положительным свободным остатком и розничной ценой; саморезы исключены. Выручка и процент рентабельности не подменяют сумму прибыли.

Для обновления отчёта: `node scripts/moysklad-profit-report.mjs "ПУТЬ_К_ЛОКАЛЬНОМУ_ФАЙЛУ_ТОКЕНА"` (только GET). Затем выполнить `node scripts/export-merchandising.mjs` и `npm run catalog:export`. Исходный отчёт сохраняется только в `private/moysklad/profit-report.json`; без него рейтинг не пересчитывается. При обновлении состава товаров сначала экспортировать ассортимент, затем пересчитать порядок и повторить экспорт. Данные отчёта, токен и себестоимость не должны попадать в публичные JSON или Git.

В текущий экспорт входят все 330 разрешённых физических товаров из складского снимка, включая позиции под заказ. Изображения категорий утверждены и подключены. Фотографии отдельных товаров остаются отдельным этапом; карточки без них показывают явное состояние «Фото готовится».

## Фильтры свойств

`app/lib/catalog-facets.ts` задаёт свойства для выбранной подкатегории: основа и нанесение смесей, тип и толщина листов, сечение и толщина профилей, размеры утеплителя, назначение грунтовок, сеток, лент и крепежа. Свойства извлекаются только из явного названия и характеристик товара. Неопределённое значение не считается подтверждённым: товар остаётся в общей выдаче, но не входит в выборку по отсутствующему свойству. Для расширения покрытия сначала дополнить подтверждённые характеристики карточек; название серии само по себе не доказывает состав или способ нанесения.

Варианты одного свойства объединяются через ИЛИ, разные свойства — через И. Счётчик варианта учитывает другие свойства, наличие, бренд и поиск. Нулевые варианты недоступны, выбранный вариант всегда можно убрать. Выбор сохраняется в параметрах `f_*` и `brand`; неподходящие значения ссылки игнорируются. Смена категории или подкатегории сбрасывает свойства и бренды, общий сброс уточнений сохраняет выбранную подкатегорию.

Проверка: `npm run catalog:facets:check` (реальные SKU, сочетания, счётчики, параметры ссылки и отсутствие потери товаров без свойств).
